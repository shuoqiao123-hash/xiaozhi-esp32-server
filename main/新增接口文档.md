# 新增接口文档

## 6. Home 模块 - 首页

**用途**: 首页设备管理与智能体绑定配置

### 类型定义

#### `DeviceWithAgent` - 设备及关联智能体（扩展自 `Device`）

> 复用 `src/api/device/types.ts` 中的 `Device`，新增 `agent` 字段

```typescript
interface DeviceWithAgent extends Device {
  agent: {                // 已绑定的智能体信息
    id: string            // 智能体ID
    agentName: string     // 智能体名称
    ttsVoiceName: string  // 音色名称
    llmModelName: string  // 大模型名称
  } | null
}
```

#### `DeviceConfig` - 设备参数配置（新增）

```typescript
interface DeviceConfig {
  volume: number          // 音量 (0~100)
  autoUpdate: number      // 自动升级开关 (1=开启, 0=关闭)
  language: string        // 设备语言代码
}
```

### 接口列表

#### `getUserDevices` - 获取用户绑定的设备列表

```
GET /home/devices
```

| 项目             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **描述**         | 获取与当前用户绑定的所有硬件设备列表，返回值包含每个设备已设定的智能体信息 |
| **请求参数**     | 无                                                           |
| **返回类型**     | `Promise<Data<DeviceWithAgent[]>>`                           |
| **是否需要登录** | 是                                                           |

---

#### `selectDevice` - 选择当前操作设备

```
POST /home/device/select
```

| 项目             | 说明                                     |
| ---------------- | ---------------------------------------- |
| **描述**         | 从设备列表中选择一台设备作为当前操作设备 |
| **请求参数**     | `data: { deviceId: string }` - 设备ID    |
| **返回类型**     | `Promise<Data<void>>`                    |
| **是否需要登录** | 是                                       |

---

#### `getCurrentDevice` - 获取当前操作设备信息

```

```

| 项目             | 说明                             |
| ---------------- | -------------------------------- |
| **描述**         | 获取当前用户已选择的操作设备详情 |
| **请求参数**     | 无                               |
| **返回类型**     | `Promise<Data<DeviceWithAgent>>` |

#### `setDeviceAgent` - 为设备绑定智能体

```

```

| 项目             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **描述**         | 为指定设备设置需要使用的智能体                               |
| **请求参数**     | `deviceId: string` - 设备ID, `data: { agentId: string }` - 智能体ID |
| **返回类型**     | `Promise<Data<void>>`                                        |
| **是否需要登录** | 是                                                           |

---

#### `updateDeviceAgentConfig` - 修改设备的智能体参数

```
PUT /home/device/{deviceId}/agent/{agentId}
```

| 项目             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **描述**         | 修改当前设备所选择智能体的运行参数（如音量、语速、提示词等） |
| **请求参数**     | `deviceId: string` - 设备ID, `agentId: string` - 智能体ID, `data: Partial<AgentDetail>` - 要更新的智能体字段 |
| **返回类型**     | `Promise<Data<void>>`                                        |
| **是否需要登录** | 是                                                           |

---

```
GET /home/device/{deviceId}/config
```

| 项目             | 说明                          |
| ---------------- | ----------------------------- |
| **描述**         | 获取指定设备的运行参数配置    |
| **请求参数**     | `deviceId: string` - 设备ID   |
| **返回类型**     | `Promise<Data<DeviceConfig>>` |
| **是否需要登录** | 是                            |


| 项目             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **描述**         | 修改设备运行参数（音量、语言、自动升级等）                   |

## 7. Mine 模块 - 我的

**用途**: 用户个人中心，包含收藏智能体、聊天记录、设备管理、账号信息

### 类型定义

#### `FavoriteAgent` - 收藏/创建的智能体（扩展自 `Agent`）

> 复用 `src/api/agent/types.ts` 中的 `Agent`，新增 `isFavorite` 字段

```typescript
interface FavoriteAgent extends Agent {
  isFavorite: boolean     // 是否收藏
}
```

#### `MineChatMessage` - 聊天记录条目（扩展自 `ChatMessage`）

> 复用 `src/api/chat-history/types.ts` 中的 `ChatMessage`，新增 `id`、`deviceAlias` 字段

```typescript
interface MineChatMessage extends ChatMessage {
  id: string              // 消息ID
  deviceAlias: string     // 设备别名
}
```

#### `AccountInfo` - 用户账号信息（新增）

```typescript
interface AccountInfo {
  avatarUrl: string       // 用户头像URL
  nickname: string        // 昵称
  phoneNumber: string     // 手机号
}
```

#### `AccountUpdateData` - 更新账号信息（新增）

```typescript
interface AccountUpdateData {
  avatarUrl?: string      // 用户头像URL（可选）
  nickname?: string       // 昵称（可选）
  phoneNumber?: string    // 手机号（可选）
}
```

#### `getMineChatHistory` - 获取当前设备聊天记录


| 项目             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **描述**         | 获取当前选中设备的聊天记录，用于跳转聊天记录界面             |

| **返回类型**     | `Promise<Data<{ total: number, list: MineChatMessage[] }>>`  |
| **是否需要登录** | 是                                                           |
